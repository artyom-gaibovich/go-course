# 🎯 Программа курса: Подготовка к собеседованиям Go-разработчика

## О курсе

Практический курс для подготовки к техническим собеседованиям на Go-разработчика. Без воды и теории — только реальные задачи, которые спрашивают на собеседованиях в продуктовых компаниях. Каждая задача включает детальное решение с объяснением временной и пространственной сложности.

**Формат:** задача → самостоятельное решение → разбор эталонного решения → понимание паттерна

---

## 📘 Глава 1: Go-специфика (26 задач)

### 1.1 Типы данных (2 задачи)

**Что вы освоите:**
- Момент вычисления аргументов `defer` — классическая ловушка, которая ловит 70% кандидатов
- Memory alignment и оптимизация размера структур — знание, которое экономит гигабайты памяти в продакшене

**Задачи:**
- `06_one_more_defer`: Разберёте, почему defer захватывает значение в момент объявления, а не вызова
- `07_type_alignment`: Научитесь правильно располагать поля в структуре, чтобы сократить потребление памяти в 2 раза

### 1.2 Строки (2 задачи)

**Что вы освоите:**
- Разница между rune и byte — фундаментальное понимание для работы с Unicode
- Безопасная работа с многобайтовыми символами

**Задачи:**
- `04_print_rune`: Почему `len(string)` не равен количеству символов и как это исправить
- `05_convert_to_byte`: Как правильно конвертировать строки в байты без потери данных

### 1.3 Слайсы (4 задачи)

**Что вы освоите:**
- Механику работы `append` и capacity — источник 90% багов со слайсами
- In-place модификации и их подводные камни
- Поведение backing array при передаче слайсов

**Задачи:**
- `06_one_more_append`: Когда append создает новый массив, а когда модифицирует существующий
- `07_modify_slice`: Почему изменения в одном слайсе влияют на другой
- `08_append_mistake`: Классическая ошибка с append в цикле
- `09_slice_magic`: Комбинированная задача на понимание slice header и capacity

### 1.4 Map (1 задача)

**Что вы освоите:**
- Недетерминированность итерации по map — критично для воспроизводимых тестов

**Задача:**
- `06_random_print`: Почему порядок вывода ключей map меняется и как с этим жить

### 1.5 Concurrency: Боевые задачи (10 задач)

**Что вы освоите:**
Реальные production-сценарии, которые требуют понимания горутин, каналов, синхронизации и race conditions.

**Задачи:**

**Streaming и real-time обработка:**
- `06_realtime_analytics`: Система сбора метрик с sliding window — как эффективно хранить данные за последние N минут
- `08_web_crawler`: Статистика загрузки страниц в реальном времени с минимальным потреблением памяти

**Rate limiting и контроль нагрузки:**
- `09_rate_limiter`: Защита API от перегрузки с точным ограничением RPS
- `10_balancer`: Load balancer с выбором наименее загруженного воркера

**Оркестрация запросов:**
- `07_request_to_url`: Параллельные HTTP-запросы с обработкой ошибок
- `11_search_in_many_services`: Агрегация результатов из множества сервисов с таймаутами

**Фоновая обработка:**
- `12_async_job`: Асинхронное выполнение задач с возможностью получения результата
- `15_task_scheduler`: Планировщик задач с отложенным выполнением

**Системы с версионированием:**
- `13_document_versioning`: Конкурентное редактирование документов с version control
- `14_top_documents`: Ранжирование документов для пользователей с кешированием и инвалидацией

**Паттерны, которые освоите:**
- Worker pools и fan-out/fan-in
- Context для отмены и таймаутов
- Channels для координации горутин
- Sync primitives (Mutex, RWMutex, WaitGroup)
- Memory-efficient sliding windows

### 1.6 Code Review: Найди ошибку (7 задач)

**Что вы освоите:**
Находить типичные баги в чужом коде — навык, который проверяют на 80% собеседований.

**Задачи:**

**Базовые проблемы архитектуры:**
- `01_bank`: Сбор курсов валют — connection leaks, SQL injection, отсутствие graceful shutdown
- `02_visits_analytics`: Аналитика посещений — race conditions и неэффективная синхронизация

**Проблемы с concurrency:**
- `03_channel_deadlock`: Почему программа зависает и как найти deadlock
- `04_http_cancel`: Неправильная обработка отмены HTTP-запросов через context
- `05_worker_pool`: Утечка горутин в worker pool
- `06_cache_race`: Race condition в кеше и неверное использование sync.Map

**API и обработка данных:**
- `07_json_api`: JSON API с проблемами в error handling и валидации

**Типичные проблемы, которые научитесь находить:**
- Resource leaks (connections, goroutines, file descriptors)
- Race conditions и data races
- Deadlocks и livelocks
- SQL injection и security issues
- Неправильная работа с context
- Memory leaks

### 1.7 Системное проектирование (2 задачи)

**Что вы освоите:**
Проектирование архитектуры и баз данных — навык senior-разработчика.

**Задачи:**
- `01_chat_and_users`: Схема БД для чата с правильными связями и индексами
- `02_slow_service`: Как спасти систему, когда один сервис тормозит весь flow (очереди, retry, circuit breaker)

### 1.8 Channels (1 задача)

**Что вы освоите:**
- Глубокое понимание работы каналов и их поведения

## 🧮 Глава 2: Алгоритмы и структуры данных (12 задач)

### Фундаментальные паттерны

Каждая задача — это не просто алгоритм, а **универсальный паттерн**, который встречается в десятках вариаций на собеседованиях.

### 2.1 Стек (2 задачи)

**Паттерн:** Стек для хранения состояния и парсинга

- `01_min_stack`: Стек с O(1) доступом к минимуму — элегантное использование дополнительной структуры
- `10_valid_parentheses`: Валидация скобочной последовательности — основа для парсинга выражений

**Где применяется:** парсеры, калькуляторы, DFS, обработка вложенных структур

### 2.2 Два указателя (6 задач)

**Паттерн:** Решение задач за O(n) вместо O(n²)

- `03_merge_sorted_arrays`: In-place слияние — мастхэв для работы с отсортированными данными
- `04_remove_nth_from_end`: Удаление элемента из linked list за один проход
- `06_remove_zeros`: Партиционирование массива in-place
- `09_k_closest`: Поиск ближайших элементов в отсортированном массиве
- `11_reverse_words`: Реверс слов с проверкой палиндромов

**Где применяется:** обработка массивов, строк, linked lists, скользящее окно

### 2.3 Hash Map (2 задачи)

**Паттерн:** Разменять память на скорость — O(n) вместо O(n²)

- `07_anagram`: Проверка анаграмм через частотный анализ
- `08_two_sum`: Классика — поиск пары с заданной суммой

**Где применяется:** поиск дубликатов, группировка, подсчет частот

### 2.4 Математические трюки (2 задачи)

**Паттерн:** Неочевидные оптимизации

- `02_is_even`: Проверка четности через битовые операции
- `12_product_except_self`: Произведение всех элементов кроме i-го без деления

**Где применяется:** низкоуровневые оптимизации, обход ограничений

### 2.5 Brute Force (1 задача)

**Паттерн:** Когда нет другого выхода

- `05_password_cracker`: MD5 brute force — рекурсивный перебор вариантов

**Где применяется:** комбинаторика, перебор с отсечениями
