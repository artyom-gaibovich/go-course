# Задача: Медленный сервис аналитики

## Проблема

Есть сервис обработки заказов. В процессе обработки заказа:
1. Пользователь создает заказ
2. Сервис заказов отправляет данные в сервис аналитики
3. Сервис аналитики обрабатывает данные (для подсчета популярности товаров)
4. После этого сервис заказов отправляет ответ пользователю

**Проблема:**
- Сервис аналитики периодически работает **медленно** или **таймаутит**
- Из-за этого мы **не успеваем ответить** пользователю
- В результате **теряем заказы** и **деньги**

```
+-------+         +---------------+    +-------------------+

```
